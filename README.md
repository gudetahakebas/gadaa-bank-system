# Gadaa Bank Board of Directors Voting Management System

A web-based voting management system developed to facilitate and manage Board of Directors elections at Gadaa Bank.

## Project Overview

The Gadaa Bank Board of Directors Voting Management System is designed to digitize and streamline the election process for selecting members of the Board of Directors.

The system provides dedicated interfaces for administrators, election officers, candidates, and voters, supporting candidate registration, voter management, electronic vote casting, and election result publication.

## Key Features

- Role-based authentication and login.
- Administrator dashboard.
- Board of Directors candidate registration and management.
- Election officer management.
- Voter registration and management.
- Electronic vote casting.
- Election results display.
- MySQL database integration.

## Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP

## System Users

1. **Administrator:** Manages users and system operations.
2. **Election Officer:** Handles election-related activities.
3. **Candidate:** Accesses candidate-related functionality.
4. **Voter:** Participates in the Board of Directors election.

## Installation and Setup

1. Install XAMPP.
2. Clone or download this repository.
3. Place the project folder inside the XAMPP `htdocs` directory.
4. Start Apache and MySQL.
5. Import `setup_db.sql` using phpMyAdmin.
6. Configure the database connection.
7. Open the application in your browser.

This academic group project was developed to apply practical knowledge of web development, database management, and software engineering to a real-world organizational voting scenario.
